## 🚀 Local Installation & Running

1. Clone or download the repository files.
2. Install dependencies (for the Vite dev server / build tool):
   ```bash
   npm install
   ```
3. Start the local development server:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.
4. To compile the production build:
   ```bash
   npm run build
   ```
   The bundled static distribution is generated in `/dist`.

---

## 🌐 Hosting & Deployment

Because this website uses pure HTML5, CSS3, and standard client-side JavaScript, it can be deployed anywhere without requiring a Node.js backend:

- **Shared Hosting / cPanel:** Upload the files directly to `public_html`.
- **Vercel / Netlify:** Connect your repository with build command `npm run build` and publish directory `dist`.
- **GitHub Pages:** Deploy static files directly to GitHub Pages.
